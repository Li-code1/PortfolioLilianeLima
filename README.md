# 💻 Meu Portfólio Pessoal (Liliane Lima)

Este é o meu portfólio pessoal de desenvolvimento Front-end, construído para demonstrar minhas habilidades em HTML, CSS e JavaScript. O projeto segue uma estrutura limpa e moderna.

## ✨ Funcionalidades Principais

* **Design Responsivo:** Adaptável a telas de desktop, tablets e celulares.
* **Alternância de Tema (Dark/Light Mode):** O usuário pode escolher entre o modo escuro (Dark Mode) ou claro (Light Mode) a qualquer momento. A preferência é salva localmente.
* **Navegação Rápida:** Seções bem definidas e acessíveis: Sobre Mim, Formação, Cursos, Projetos e Contato.
* **Foco em Fundamentos:** Construído puramente com HTML, CSS e JavaScript (Vanilla JS).

## 🚀 Tecnologias Utilizadas

| Categoria | Tecnologia | Uso |
| :--- | :--- | :--- |
| **Estrutura** | `HTML5` | Definição da estrutura do conteúdo. |
| **Estilização** | `CSS3` | Design, layout e implementação da funcionalidade de **Variáveis CSS** para o Dark Mode. |
| **Interatividade** | `JavaScript` (Vanilla JS) | Lógica para alternar e salvar a preferência do tema (Dark/Light Mode) no `localStorage`. |
| **Design/Wireframe** | `Figma` | Ferramenta citada como base para planejamento de interfaces. |

## 📂 Estrutura do Projeto

```

.
├── index.html          \# Estrutura principal e conteúdo
├── style.css           \# Estilos e variáveis para Light/Dark Mode
├── main.js             \# Lógica do JavaScript para a alternância de tema
└── README.md           \# Este arquivo

````
